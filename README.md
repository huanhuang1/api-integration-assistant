# BNY API Integration Assistant — Technical Proposal

This branch contains the current English proposal and its architecture diagram. It describes a proposed LangChain assistant for finding API workflows, retrieving API specifications and business rules, and generating integration guidance. The prototype has not been implemented; all example APIs and rules are fictional.
