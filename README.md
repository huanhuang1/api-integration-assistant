# BNY API Integration Assistant Prototype Plan

This branch contains a simplified English prototype plan and its architecture diagram. It covers what to ingest, how vector search finds a workflow, how application code reads the full API records, and how the assistant answers an account-opening question. The prototype has not been implemented; all example APIs and rules are fictional.
